# ♟️ Chess AI Engine

This is a chess engine built using Python with a graphical interface using Pygame.

## 🚀 Features

* Alpha-Beta Pruning (Minimax Algorithm)
* Heuristic Evaluation Function
* Move Ordering Optimization
* Transposition Table
* Graphical Chess Board (Pygame)
* Play as White or Black

## 🧠 AI Logic

The AI evaluates board positions based on:

* Material balance
* Pawn positioning (piece-square table)
* Game state (checkmate detection)

## 🛠️ Technologies Used

* Python
* Pygame
* python-chess

## ▶️ How to Run

Install dependencies:
pip install pygame python-chess

Run the program:
python chess_final.py
